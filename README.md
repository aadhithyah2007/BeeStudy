# 🐝 BeeStudy – AI-Powered Study Assistant

BeeStudy is a futuristic study assistant designed to help students learn more effectively through interactive quizzes, study tracking, and personalized recommendations.

## Features
- Interactive study dashboard
- Topic-based quizzes
- Study progress tracking
- Personalized study recommendations
- Futuristic user interface

## Technology Stack
- Python
- Streamlit
- JSON for storing study results

## How to Run Locally

1. Clone or download this repository.
2. Install the required packages:

   `python -m pip install -r requirements.txt`

3. Start the application:

   `python -m streamlit run dashboard.py`

## Data Notice
The current version uses simulated study-session data and rule-based responses. It is a prototype and is not connected to a physical Bee wearable or an external AI model.
